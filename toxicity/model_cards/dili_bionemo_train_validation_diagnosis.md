# MegaMolBART train/validation-only diagnosis

Date: 2026-09-19. Status: **exploratory diagnosis, not a replacement model**.
The user requested this follow-up after seeing the initial fixed-head test result.
It is not retrospectively part of the original prespecified experiment.

## Boundary and protocol

- Reuse the exact checksummed MegaMolBART cache and frozen partitions.
- Use only 539 training and 158 validation labels. Full-cohort data/cache checksums
  and structural integrity are verified, but test labels are never extracted for
  analysis and no test predictions/metrics are generated by this diagnostic.
- Five L2 logistic penalties specified before this diagnosis: `C=1, 0.1, 0.01,
  0.001, 0.0001`. Smaller C means stronger regularization.
- Keep all 512 features. StandardScaler fits on training only, and separately on
  each fitting fold for 3-fold scaffold/connectivity-grouped training CV (seed 42).
- Report every candidate. Validation thresholds use the existing balanced-accuracy
  rule; no probability calibrator, feature selector, MLP or deployed model is fitted.
- Do not rerun the original test evaluation to choose between these candidates.
  The original report, RF model, split and v2 interface remain unchanged.

## Interpretation

**Strong evidence of overfitting/overconfidence in the original logistic head.**
Perfect training discrimination contrasts with much weaker group-held-out and
validation discrimination. Penalizing the coefficients more strongly improves
probability error in both development checks. This is not proof that regularization
is the only cause of limited performance or that the embeddings lack useful signal.

No collapsed/constant feature was found. The 512-dimensional standardized training
matrix has full column rank, but correlated features concentrate 95% of variance in
116 principal components (descriptive calculation only; no PCA transformation was
used). Per-feature training standard deviations range from 0.181 to 1.268.
Absolute validation mean shifts in training-standard-deviation units have median
0.095 and maximum 0.407. These checks found no obvious scaling failure; they do not
rule out higher-order chemical distribution shift.

C=0.001 has the strongest validation point estimates in this grid, while training
CV favors C=0.1 on AP and C=0.01 on AUROC. Thus no single value wins every criterion.
Regularization substantially helps probability error, but discrimination improves
only modestly. Do not select a replacement from these reused validation results or
claim superiority to the RF. There is no demonstrated need to add MLP complexity.

Any next modeling study should explicitly freeze its primary selection metric and
training-grouped tuning procedure, with fresh untouched evaluation data for a
confirmatory improvement claim. Repeated use of this validation set adds optimism;
this follow-up was also motivated by an already observed test outcome. Outputs remain
drug-level concern scores, not patient incidence or proof of safety. Exact ZINC15
pretraining overlap remains unknown.

## Reproduce offline

```sh
toxicity/.venv/bin/python -m toxicity.src.bionemo_diagnostics
toxicity/.venv/bin/python -m pytest toxicity/tests/test_bionemo_diagnostics.py -q
```

Uses the existing ignored `artifacts/embeddings/megamolbart_dilirank2.json` cache;
no GPU, network or API credential is needed. Writes a new report to
`artifacts/runs/megamolbart_train_validation_diagnosis.json` and refuses to overwrite
an existing file. For a deliberate reproduction, pass `--output` with a fresh path.
The report includes exact input/cache/script hashes, package versions, all CV fold
memberships, convergence iterations, coefficients' norms and reliability summaries.
