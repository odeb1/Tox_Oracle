        METHODS & LOCAL SETUP
        A traceable research workflow.
        The workspace coordinates the repository’s existing science. Rankings and DILI predictions retain their original definitions.
        Local readiness
        These are file and credential presence checks. Execution preflight checks the scientific environment and cache integrity; the privacy scanner verifies its checkpoint before use.
        OPTIONAL RESEARCH ASSISTANT
        NVIDIA Nemotron
        Sends a fixed interface-check greeting to NVIDIA, with no research data. A successful check must report the configured Nemotron identity. No study data is sent by this check.
        The scientific sequence
        1. Prepare locally. Validate and standardize compound identity using the existing toxicity component. A successful imatinib reference gates the remaining panel.
        2. Propose candidates when needed. With no dataset, GenMol uses the documented imatinib fragment. Local chemical checks and diversity selection choose up to 20 candidates; the separate reference is never shortlisted. No DILI feedback guides generation.
        3. Screen with Boltz-2. Use the checked-in ABL1 target and fixed inference settings. Binding likelihood, affinity and structural confidence are stored separately.
        4. Freeze discovery. Rank by descending mean returned binder likelihood, breaking exact ties by compound ID. Freeze the top two before DILI inference.
        5. Predict human DILI locally. Use the trained model artifact and its threshold, without retraining. Preserve applicability, uncertainty and training membership.
        6. Apply follow-up policy. Elevated DILI concern in a shortlisted candidate prompts targeted liver validation. Lower concern supports target validation alongside routine liver testing. Missing evidence remains incomplete.
        Nemotron, when enabled, requests the bounded ABL1 workflow and explains its results. The app verifies the returned model identity. The backend validates its plan and controls all scientific operations. Its prose cannot change scores, rankings, approvals or follow-up rules.
        Running this workspace
        ./scripts/toxoracle-web
        See docs/runbooks/research-workspace.md for installation, artifact paths, API setup and recovery. The execution workspace binds to 127.0.0.1. Hosted access requires a separate local companion design.
