        METHODS & LOCAL SETUP
        A traceable research workflow.
        The workspace coordinates the repository’s existing science. Rankings and DILI predictions retain their original definitions.
        Local readiness
        These are file and credential presence checks. Execution preflight checks the scientific environment and cache integrity; the privacy scanner verifies its checkpoint before use.
        OPTIONAL RESEARCH ASSISTANT
        GPT-Rosalind
        Sends a fixed interface-check greeting to OpenAI, with no research data. A successful call must also report a Rosalind model identity. The Workbench launcher is not used.
        The scientific sequence
        1. Prepare locally. Validate and standardize compound identity using the existing toxicity component. A successful imatinib reference gates the remaining panel.
        2. Screen with Boltz-2. Use the checked-in ABL1 target and fixed inference settings. Binding likelihood, affinity and structural confidence are stored separately.
        3. Freeze discovery. Rank by descending mean returned binder likelihood, breaking exact ties by compound ID. Freeze the top two before DILI inference.
        4. Predict human DILI locally. Use the trained model artifact and its threshold, without retraining. Preserve applicability, uncertainty and training membership.
        5. Apply follow-up policy. Elevated DILI concern in a shortlisted candidate prompts targeted liver validation. Lower concern supports target validation alongside routine liver testing. Missing evidence remains incomplete.
        Rosalind, when verified and explicitly enabled, explains the fixed plan and its results. Its prose cannot change scores, rankings, approvals or follow-up rules.
        Running this workspace
        PYTHONPATH=app/src:discovery/src:. app/.venv/bin/python -m toxoracle_app.web
        See docs/runbooks/research-workspace.md for installation, artifact paths, API setup and recovery. The execution workspace binds to 127.0.0.1. Hosted access requires a separate local companion design.
