    METHODS & SETUP

    Real evidence. Clear boundaries.

    What you are exploring

    A static, interactive replay of two real ABL1 runs from 20 September 2026. No model is running in this website. The original assistant was NVIDIA Nemotron, not Rosalind; a callable Rosalind API was unavailable.

    The product vision extends toxicity assessment across organs, including the liver, heart and kidneys. The current demo illustrates liver toxicity.

    In the current ABL1 implementation, supplying candidate structures selects screening; without candidates, the workflow prepares generation. After privacy approval, Nemotron interprets the question and validates the supported plan. Broader prompt-driven model routing is part of the product direction.

    The scientific sequence

    1. Review and approve sanitized inputs using the independent local privacy filter.
    2. For target-only requests, GenMol proposes structures from the documented imatinib fragment. Chemical validity and diversity determine selection, without DILI feedback.
    3. Boltz-2 screens the prepared human ABL1 domain. Binding likelihood, predicted affinity and structural confidence remain separate.
    4. Select the top two candidates by mean binder likelihood before DILI.
    5. The local DILI baseline predicts drug-level human liver concern. The provisional policy recommends follow-up; held candidates are never automatically replaced.

    The primary run contains 20 generated candidates, 18 successful discovery results and two failures. Both shortlisted candidates need liver validation. Generated molecules are not a labelled evaluation cohort. The four supplied drugs overlap model fitting or selection and are not unseen evaluation cases.

    Predicted binding is not measured efficacy. DILI scores are not dose-specific outcomes or an assurance of safety. Binding and DILI scores cannot be subtracted. Model evaluation belongs to its held-out reference set, not these demo candidates.

    Privacy and persistence

    New prompt text and file contents never leave this page or enter browser storage. Only the selected example, reached step and playback position are remembered. Refresh restores paused playback. Reset clears that progress. There are no analytics or accounts.

    Run a new study locally

    The existing local app handles new inputs, real privacy filtering, approval and live provider calls. It accepts free-text targets, but execution currently supports the prepared ABL1 domain; other targets need preparation. Connecting a local privacy companion to hosted execution remains future work.
