# Runtime and deployment

Add Brev setup, containers and deployment configuration only as the runtime is chosen. Pin image/dependency versions. Keep credentials and local overrides out of Git. A scaffold does not imply a deployed service.

`diffdock_smoke.py` runs the public NVIDIA connectivity example; see the
[DiffDock runbook](../docs/runbooks/team-a-diffdock.md).
`prepare_pparg_demo.py` prepares a proposed target, experimental reference, and
shared candidate requests from local public inputs; see the
[target-preparation runbook](../docs/runbooks/team-a-target-preparation.md).
