# Shared configuration

Version non-secret integration and triage settings here. Every priority rule needs a version and documented score meanings. Team-specific model/target settings live with their workstream.

`triage-v1.json` is the current provisional policy and validates against `triage.schema.json`. An approved policy must include a method-specific applicability threshold; the provisional policy intentionally keeps that threshold `null` until Team B and the biologist approve it.
