# Target configurations

One manifest per prepared target: protein/species, accession, PDB ID, chain, preparation choices, reference ligand, artifact URI/checksum and source. Store downloaded structures under local artifacts/; commit small public fixtures only when needed.

`pparg-7awc/` contains a proposed human PPARgamma target and v2 candidate/control
requests. It preserves the existing dataset identities and records unresolved
preparation and stereochemistry decisions. See the
[target-preparation runbook](../../../docs/runbooks/team-a-target-preparation.md)
for sources, reproduction, validation, and selection status.
